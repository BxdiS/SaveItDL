# SEO & Growth Plan — All Downloader Bot

## 1. Название бота

### Требования
- Содержит ключевое слово (save/grab/dl/get + video/media/all)
- Уникальное — не занято в Telegram
- Легко запоминается, легко диктуется голосом
- Работает в поиске Telegram и Google

### Варианты (от лучшего к запасному)
Проверь каждый в @BotFather командой /newbot → ввести username

| Username | Почему может быть свободен |
|---|---|
| `@SnapSaveItBot` | 3 слова, специфичная комбинация |
| `@RipMediaBot` | "rip" = скачать, нишевый термин |
| `@DLitBot` | короткое, "dl it" = скачай это |
| `@SaveLinkzBot` | z делает уникальным |
| `@GrabItNowBot` | длинное = скорее свободно |
| `@AllDLRobot` | Robot вместо Bot — чаще свободно |
| `@SnatchVidBot` | snatch = хватай, редкое |
| `@MediaRipBot` | точно описывает функцию |
| `@QuickDLBot` | quick + dl — хорошие ключевики |
| `@GetMediazBot` | z на конце = уникальность |

**Рекомендация:** начни с `@RipMediaBot` или `@QuickDLBot` — короткие, понятные, содержат ключевые слова.

## 3. Бесплатная реклама — пошаговый план

### Неделя 1: Базовое присутствие

- [ ] **Каталоги Telegram-ботов** (30 мин, даст 50-300 юзеров/мес)
  - https://t.me/taborbot — отправить бота на модерацию
  - https://botlist.co — зарегистрировать бота
  - https://telegrambots.info — добавить в каталог
  - https://botostore.com — русскоязычный каталог
  - Искать в Telegram: "каталог ботов", "bot list" — добавляться во все

- [ ] **BotFather inline-поиск** (5 мин)
  - Включить inline mode в @BotFather
  - Заполнить все поля: about, description, short description
  - Добавить аватарку (яркую, с иконкой скачивания)

### Неделя 2: GitHub + лендинг

- [ ] **GitHub-репозиторий** (1 час, SEO-трафик из Google)
  - Публичный репозиторий с хорошим README
  - README на русском + английском
  - Заголовок: "Telegram Bot — Download Videos from Any Site (TikTok, YouTube, Instagram, ...)"
  - Topics/tags: `telegram-bot`, `video-downloader`, `tiktok-downloader`, `youtube-downloader`, `media-downloader`, `python`, `yt-dlp`
  - Добавить бейджи: Python, License, Stars
  - Секция "Try it now" с прямой ссылкой на бота

- [ ] **GitHub Pages лендинг** (30 мин, бесплатный сайт)
  - Одностраничник с кнопкой "Open in Telegram"
  - Title: "Free Video Downloader Bot for Telegram — TikTok, YouTube, Instagram"
  - Ключевые слова в тексте: "скачать видео с тикток бесплатно", "download tiktok video without watermark"
  - Адрес: username.github.io/bot-name

### Неделя 3: Форумы и Reddit

- [ ] **Reddit** (30 мин, может дать 100-500 юзеров разово)
  - r/Telegram — "I built a free bot that downloads from any site"
  - r/TelegramBots — пост + демо
  - r/selfhosted — если open source
  - r/Python — "I built this with yt-dlp + aiogram"
  - Формат: не реклама, а "I made this, feedback welcome"

- [ ] **4PDA** (30 мин, русскоязычная аудитория)
  - Раздел "Telegram" → создать тему
  - Подробное описание + скриншоты

- [ ] **Pikabu / Habr** (1 час)
  - Пост "Как я написал бота для скачивания видео из любого источника"
  - Технический + пользовательский контент

### Неделя 4: Telegram-каналы

- [ ] **Каналы с подборками ботов** (бесплатно/бартер)
  - Искать: "полезные боты", "telegram лайфхаки", "подборка ботов"
  - Написать админам: "привет, сделал бота — может подойдёт для подборки?"
  - Предложить бартер: упоминание их канала в боте за пост

- [ ] **Тематические каналы** (бесплатно)
  - Каналы про TikTok — "бот для скачивания без водяного знака"
  - Каналы про музыку — "бот для скачивания с SoundCloud"
  - Каналы про контент-мейкинг — полезный инструмент

### Постоянно: Виральный рост

- [ ] **Сарафанное радио в самом боте**
  - После каждой загрузки (бесплатных юзеров): подпись "Downloaded via @BotUsername"
  - Кнопка "Share with friends" в /start
  - Реферальная система: пригласи 3 друзей → +5 загрузок/день

- [ ] **Обновления**
  - Канал @BotUpdates — новости, новые фичи, статус
  - При добавлении новых сайтов — пост в канал
  - Юзеры подписываются → напоминание о боте

## 5. Аватарка бота

Требования:
- Яркий цвет (фиолетовый/оранжевый — выделяется в списке чатов)
- Иконка стрелки вниз (↓) — узнаваемый символ скачивания
- Текст: название бота или "DL"
- Размер: 512x512 px
- Без мелких деталей — должно читаться в 30px кружке

Сделать бесплатно: Canva, Figma, или попросить ChatGPT/DALL-E
