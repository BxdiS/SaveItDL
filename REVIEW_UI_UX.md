# UI / UX Review

Собрано по коду `platforms/telegram.py` и опыту работы с Telegram Bot API 7+.

## Про «цветные кнопки»

В inline-клавиатурах Telegram цвет кнопок **нельзя задать произвольно**. Все `callback_data`- и `url`-кнопки серые. Есть только четыре кнопки, у которых Telegram сам рисует другой стиль:

| Кнопка | Как выглядит | Когда использовать |
|---|---|---|
| `WebAppInfo` | Синяя, с иконкой мини-приложения | Открыть мини-приложение (например, полный экран статистики). |
| `pay=True` | Зелёная, с иконкой карты | Только в счетах на оплату (Telegram Stars или обычные платежи). |
| `login_url` | С замком, «логин» | Быстрая авторизация на сайте. |
| `url` на `https://t.me/...` | Стандартная серая, но со стрелкой | Ссылки на каналы, чаты, ботов. |

Практический выход: чтобы визуально выделить главное действие, нужно либо сделать **WebApp**-кнопку (что стоит того — можно вынести туда статистику, историю, VOD-обрезку с ползунком), либо использовать эмодзи как «якорь» для глаза (мы уже делаем это в HELP/WELCOME).

Роадмап-запись: `v1.2 → Web App button для стат-раздела`. Даст «настоящую» синюю кнопку в /start.

## Обязательные исправления

### 1. Кнопка `📎 Отправить ссылку` — фейковая кнопка
**Было:** `menu:hint` открывал `answer("...", show_alert=True)` — модальный попап с текстом «просто отправь ссылку». Это дважды бесполезно: пользователь уже видит подсказку рядом, и модалка блокирует чат.

**Исправлено:** удалил кнопку и её обработчик в этом PR. WELCOME теперь короче и понятнее без неё.

### 2. Английские названия в reply-клавиатуре
**Было:** `📊 My Stats`, `❓ Help` — а всё остальное на русском.

**Исправлено:** `📊 Статистика`, `❓ Помощь`.

### 3. Разделители ━━━ во всех сообщениях
**Было:** декоративные заголовки-«таблички». Занимают три строки на ровном месте, читаются как «AI-сгенерированный интерфейс».

**Исправлено:** заменил на короткие bold-заголовки (`📊 <b>Твоя статистика</b>`). Все панели и статусы стали компактнее в 2-3 раза.

### 4. Строка «📎 Лимит файла: 50 МБ» в /help
**Убрано** по запросу. Если пользователь упрётся в лимит — увидит конкретную ошибку с фактическим лимитом (50 МБ для дефолтного API или 2 ГБ для локального).

### 5. Канал `SaveItDLnews` → `SaveItDL`
Обновлён URL в `WELCOME_KEYBOARD`.

### 6. Баг в кнопке «Моя статистика» из /start
**Было:** обработчик `menu:stats` вызывал `_send_user_stats(callback.message)`. Но `callback.message.from_user` — это **бот**, а не пользователь. То есть при нажатии кнопки бот всегда искал свою собственную статистику и показывал «пока нет скачиваний».

**Исправлено:** сигнатура `_send_user_stats(user_id, message)` теперь явно принимает id. Все вызывающие места передают правильный id (`callback.from_user.id` для callback-ов, `message.from_user.id` для команд).

## Что улучшить дальше (не в этом PR)

### 7. Прогресс-бар при скачивании
Сейчас: одно сообщение «⬇️ Скачиваю…» без движения. Пользователь на большом файле думает, что бот завис.

Что сделать: в `Downloader.download` уже пробрасывается `progress_hooks`. Нужно подцепить его к `status_msg.edit_text` — каждые 5-10% редактировать сообщение. Осторожно с Telegram rate-limit: не чаще 1 редактирования в 2-3 секунды. Например:

```python
last_edit = 0
def on_progress(status, pct):
    nonlocal last_edit
    now = time.time()
    if now - last_edit < 2 or pct < 5:
        return
    last_edit = now
    bar = "▓" * int(pct/10) + "░" * (10 - int(pct/10))
    asyncio.create_task(status_msg.edit_text(f"⬇️ {bar} {pct:.0f}%"))
```

### 8. Короткие видео как «кружки»
Video note (`answer_video_note`) — красиво для <60s TikTok/Reels. Условие: `result.duration < 60` и `result.filesize < 8MB` и квадратное соотношение (не критично — Telegram сам обрежет).

### 9. Превью в выборе формата
`info.thumbnail` уже есть в `MediaInfo`. Можно вместо `edit_text` присылать `answer_photo(photo=info.thumbnail, caption=..., reply_markup=kb)`. Требует лёгкой перестройки — заменить одно сообщение на два: статус + фото с выбором.

### 10. Кнопка «Повторить» на ошибке
Сейчас пользователь после ошибки должен снова копировать ссылку. Можно давать `retry:{url_id}` callback (URL уже в `_pending_urls`).

### 11. Кнопка «Отменить» во время скачивания
При `queue_pos > 0` показывать `❌ Отменить`. Callback снимает из очереди (нужен способ пометить job как cancelled в WorkerPool).

### 12. i18n
Всё на русском. У нас в `users` есть `language_code`. Готовые переводы для 3 языков (RU/EN/ES) закрывают 90% аудитории. Не blocker для запуска, но задел.

### 13. Reply-клавиатура одноразовая по контексту
Постоянная клавиатура снизу закрывает пространство. Можно `is_persistent=False` и показывать её только на /start, скрывать после первой отправки ссылки (`ReplyKeyboardRemove`).

### 14. WebApp-кнопка для расширенной статистики
Пункт в роадмапе v1.2. Мини-приложение показывает историю, графики, топ-платформы за месяц — то, что не влезает в текстовое сообщение. Плюс: получим ту самую «цветную» синюю кнопку.

### 15. Команда `/help` теперь есть
Добавлена в этом PR (в reply-кнопке была, но команды `/help` не было — не совпадало с BotFather-подсказкой).

### 16. Приветственное сообщение с баннером — слишком «жирное»
Сейчас: photo + caption + отдельное сообщение «⬇️ Вставь ссылку» с reply-клавиатурой = **два сообщения** на одну команду. Второе сообщение вылезает под фотографию и выглядит как спам.

Вариант: reply-клавиатура и так persistent, показывать её сразу с баннером. Отдельное «⬇️ Вставь ссылку» — убрать. Или использовать HTML-blockquote вместо инструкции.

### 17. Форматы: `.webm` и `.mp4` в подписи кнопок
Пользователю всё равно, какой контейнер. Показывать только качество + размер:

```
🎬 1080p · 42MB
🎬 720p · 18MB
```

Строка `f.ext` в `_build_video_buttons` — на выброс.

### 18. VOD-подсказка длинная
После «пришли диапазон» пользователю всё равно нужно набирать `0:00 - 15:00` руками. Можно кнопки-пресеты: «первые 15 / 30 / 60 мин», «последние 30 мин», отдельная кнопка «Ввести вручную».

### 19. Кнопки в админ-навигации: текущий раздел скрыт
`_admin_nav(current)` пропускает текущую вкладку — это ок, но пользователь теряет якорь. Показывать её неактивной кнопкой (с эмодзи-точкой) или оставить, но подсветить в заголовке (`📊 <b>Admin · Users</b>`).
